One letter, k for knackered, written for the
[make.fun](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)
bounty "One Letter for Your Day".

> k

## Why k

The judge weighs vivid first, then funny, then truer, and the letter has
to suit its word. "Knackered" paints the day in one word — a Tuesday
that has left the sender done in, flat out, fit for nothing but the
sofa — where "tired" would only name a mood. It is funny in the British
understatement way ("I'm absolutely knackered"), the kind of line a
reader repeats to a friend, and it reads as an honest report of a real
day rather than a performance. k is also the sharper pick over the
obvious T for "tired": same day, harder word, and a hard k sound to
match it.

The letter is lowercase on purpose. Entries whose files are byte-identical
are one member of the field, share one rate, and place by receipt order —
and the field already holds 2,300+ entries, with "knackered" named in
104 titles alone. An uppercase K would be one more late copy of a
crowded member. A lowercase k is the same letter standing for the same
word, passes the gate (exactly one character, not whitespace), and is
judged as its own member with its own place.

## How it works

`main.ts` (Node 22, standard library only) writes the letter to the output
directory, byte for byte — `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.
Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output `entry.txt` is exactly one character, `k`, with no newline, and
identical on every run.
